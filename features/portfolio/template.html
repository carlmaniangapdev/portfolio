    06 / HOW I WORK

    Start with the problem.
    Build toward clarity.

    01

    Understand the goal

    I ask questions, learn who will use the app, and define what a useful result should look like.

    02

    Plan a simple path

    I break the work into manageable parts and choose an approach that fits the problem without adding unnecessary complexity.

    03

    Build in small steps

    I keep the code organized, connect each part carefully, and check the result as I go instead of waiting until the end.

    04

    Test, listen, and improve

    I test the main flow and edge cases, gather feedback, and refine the details that make the app easier to use and maintain.
